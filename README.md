# AZ-104 Azure Administration Labs

This repository documents the five core Azure administration labs I built to establish a production ready cloud foundation. Each lab focuses on a major operational pillar used by enterprise cloud teams and MSPs, with hands‑on tasks, real world notes, and repeatable workflows.

# 📂 Lab Structure
- 01 Identity & Access Management  
Covers users, groups, RBAC, managed identities, and governance fundamentals.
- 02 Compute & Virtual Machines  
VM deployment, disks, extensions, availability, and VM‑level backup.
- 03 Networking & Connectivity  
VNets, subnets, NSGs, peering, VPN gateways, private endpoints, load balancing.
- 04 Storage & Backup  
Blob storage, file shares, lifecycle management, backup vaults, recovery services.
- 05 Analytics & Logs  
Log Analytics, metrics, alerts, dashboards, diagnostic settings, KQL.

# What Each Lab Contains:
- A detailed walkthrough of what I built
- Notes and observations from real Azure usage
- Screenshots of the Azure portal
- PowerShell and CLI equivalents
- Architecture diagrams
- Practical admin workflows

This repo represents the foundation of Tremols Tech’s internal Azure practice and my own progression toward becoming a Cloud Administrator.
